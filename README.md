
# Robotic-Dog-Electrical

Electrical engineering files for the robotic dog. This repository is intended for component datasheets, schematics, PCB designs, and other EE-related documentation for the project.

## Documentation

The electrical research, component comparisons, and design considerations are in the [wiki](https://github.com/artorias961/Robotic-Dog-Electrical/wiki).

| Page | What it covers |
|---|---|
| [00 ‐ ADC](https://github.com/artorias961/Robotic-Dog-Electrical/wiki/00-%E2%80%90-ADC) | ADC fundamentals, architectures, and design considerations |
| [01 ‐ Current Sensor](https://github.com/artorias961/Robotic-Dog-Electrical/wiki/01-%E2%80%90-Current-Sensor) | Current-sensing technologies, component comparisons, and trade analysis |

## Software

The only software required for schematic and PCB design is [KiCad](https://www.kicad.org/).

| Software | Purpose |
|---|---|
| KiCad | Create and edit electrical schematics, PCB layouts, and related design files |
